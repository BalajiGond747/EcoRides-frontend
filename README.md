# EcoRides Frontend

EcoRides is a React frontend for an EV rental platform. It provides user and administrator interfaces for browsing vehicles, making bookings, managing accounts, processing payments, and viewing invoices.

## Tech Stack

- React
- JavaScript
- React Router
- Tailwind CSS
- Axios
- Lucide React
- React Toastify
- Razorpay

## Features--

### User
- Registration and OTP verification
- Login and logout
- Forgot password
- Profile management
- Change password
- Change email
- Browse EVs
- Booking management
- Vehicle availability
- Razorpay payment
- Invoice viewing and download

### Admin
- Dashboard
- Car management
- Location management
- Coupon management
- Booking management
- Payment management
- User management
- Admin management
- Admin profile
